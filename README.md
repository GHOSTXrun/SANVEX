# SANVEX

An x402-compatible security layer for verifiable agent payments.

## Website

Static, English-language frontend featuring the SANVEX logo, animated transaction paths, orbital graphics, and a responsive dark interface. The animation illustrates the protocol flow; it does not display live transactions.

Open `index.html` in a browser. No build step or dependencies are required.

## Files

- `index.html`: website content and protocol illustration.
- `main.css`: base layout and typography.
- `visual.css`: visual theme, animation, and responsive styling.
- `sanvex-logo.png`: project logo.

## Hosting

The site can be served by any static host. For GitHub Pages, select the `main` branch and `/ (root)` in the repository's Pages settings.

## Status

Protocol specification: draft. Facilitator: in development. SDK and test suite: planned. This repository contains the presentation website, not a production payment service.
